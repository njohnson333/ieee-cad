# NJIT IEEE CAD & 3D Printing website

This is the static website ready for GitHub Pages. Keep `index.html`, `class-material.html`, `.nojekyll`, and the `assets` folder together at the root of your publishing branch.

## Publish on GitHub Pages

1. Create a GitHub repository, for example `ieee-cad`.
2. Extract this ZIP and upload its *contents* (not the ZIP file) to the repository root on `main`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
5. GitHub will show your site URL. For a repo named `ieee-cad`, it is usually `https://YOUR-USERNAME.github.io/ieee-cad/`.

To use `https://YOUR-USERNAME.github.io/` without the repository path, name the repository `YOUR-USERNAME.github.io` instead. The HTML uses relative links, so it works in either location.

The Week 1 Slides button links to a Google Slides deck; make sure students have access to that deck. The other weekly resource slots are still marked as coming soon.
